# Project Kickoff — Bank Performance Management System

## Main Goal

Build a web-based **Bank Branch Staff Performance Management System** for one Bank of Abyssinia branch. The system will allow branch staff to record their daily Key Performance Indicator (KPI) performance while enabling management to monitor performance and provide feedback on a daily, weekly, monthly, and quarterly basis.

## Initial One-Week Priorities

1. Understand and finalize the requirements.
2. Define the system structure.
3. Build the initial prototype.
4. Review and prepare for development.

The first week should focus on requirements review, system structure, and development workflow so the team can divide the work and move efficiently.

## Important Requirement Boundary

We should **not invent the bank's actual KPIs, targets, or formulas**. These must be confirmed by branch management before implementation.

The system should therefore be designed so that approved KPIs, targets, formulas, and performance rules can be configured rather than hard-coded from assumptions.

## Project Discussion

Team members should share ideas, questions, and suggestions in the project discussion space so requirements, decisions, and tasks remain organized.

## Initial Project Objective Statement

The main objective is to timely monitor branch staff performance by granting users access to record their daily KPI performance. Management will review performance and provide feedback on a daily, weekly, monthly, and quarterly basis.

The system should include a performance dashboard showing KPI performance and each staff member's status, an announcements area for meetings, holidays, and other notices, and an internal chat room for communication.
